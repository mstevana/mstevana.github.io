# Crawl

A first-person dungeon crawler on open d20 rules, in one self-contained HTML
file. Three.js from a CDN, no build step, made for a phone held sideways.

**Play it: https://mstevana.github.io/crawl/**

Add it to your home screen and it runs full-screen, offline-tolerant, with its
own icon. Saves live in the browser and can be exported as a code from the menu.
